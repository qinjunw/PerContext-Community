# 社区版架构

项目包含一个 Android `:app` 模块，使用 package 划分代码边界。

| 目录 | 职责 |
|---|---|
| `core` | 音频解码、重采样、播放和格式化 |
| `domain` | 录音、转写、每日回顾模型与用例，以及外观设置契约 |
| `data` | Room、文件存储、SenseVoice、模型 HTTP 客户端和加密设置 |
| `feature` | Compose 页面和 ViewModel |
| `service` | 录音前台服务、转写与回顾后台任务 |
| `ui` | 六组昼夜配色、主题提供器与共享界面组件 |

录音先发布到公共音频目录，再登记数据库。用户主动发起转写，后台任务使用 APK 内置的固定 SenseVoice 模型，按 PCM 窗口解码识别。模型文件通过长度及 SHA-256 校验后才交给原生运行时。

每日回顾根据设备时区选择一个自然日的成功转写，生成带来源编号的模型输入。模型返回须通过结构校验，才写入本地回顾。失败和取消保留上一次成功回顾。

模型设置包含预设或用户自定义的 HTTPS 地址、模型名称与 API Key。地址和模型名保存在 DataStore，Key 经 Android Keystore AES-GCM 加密后保存。网络调用从同一份设置快照取得地址和 Key；更换地址时不能自动复用原地址的 Key。客户端使用系统 TLS 信任和主机名验证，并拒绝重定向。

普通构建不读取运营服务器配置。应用数据、模型源和签名材料均保存在 Git 忽略的位置。

外观设置使用独立的 `appearance_settings` DataStore，保存主题和显示模式两个稳定字符串值。`AppearanceViewModel` 在写入成功、仓库流发出新值后更新外观；单项写入保留另一项，未知值分别回退到晴空奶白和跟随系统。它不读写模型服务的 DataStore 或 API Key。

`MainActivity` 根据保存的外观与系统昼夜状态选择调色板，加载设置并应用外观后才允许绘制首帧，同时更新系统栏图标明暗。`PerContextTheme` 提供 Material 色彩角色及录音卡、皮蛋平台等扩展颜色；已有颜色属性通过组合环境读取当前主题。录音卡改用主题色绘制底部波纹，避免浅色位图覆盖夜间底色。

`PidanPerch` 将原生矢量分为身体、尾巴、头部和爪子四层，在记录页与回顾页的上下组件之间预留空间。身体与头部按 4 秒周期呼吸、点头，尾巴每 8 秒摆动一次，爪子与平台固定。动画只在页面处于前台时运行，尊重 Compose 动画时长设置；录音时保持静止。回顾页在高度不足时整体滚动，保留日期操作与生成回顾按钮的访问空间。
