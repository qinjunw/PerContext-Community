### 尚待设备验证

以下步骤尚未在社区版安装包上实测。自动化测试使用测试配置和模拟模型响应，未调用用户的真实云端模型。

1. 在 ARM64 Android 设备上安装 Release APK，授权麦克风后录制、停止和播放一段测试音频。
2. 断开网络，对该录音发起首次转写，确认内置模型安装完成并生成文字；再次转写无需下载模型。
3. 联网，在设置中填写自己的 HTTPS 地址、模型名称和 API Key，保存后重新打开设置，确认配置保留且 Key 默认隐藏。
4. 对测试日期生成回顾，确认标题、摘要和来源关系可以查看；关闭并重开 App 后仍可读取。
5. 将服务地址改为另一地址，确认必须重新输入 Key；使用无效 Key 或断网时确认错误提示和上次成功回顾仍保留。
